# Farm App v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the sheep-only "Ma Ferme" Flutter/Firebase app into a complete multi-species farm management system (animals, crops, fields with rent, sales, reports, reminders), per `docs/superpowers/specs/2026-05-18-farm-app-v2-design.md`.

**Architecture:** Drift schema v2 (drop & recreate, no migration), 10 tables (species, animals, farm_id_counters, fields, crops, expenses, sales, reproduction_events, health_events, reminders, settings — history table kept). Repository → Riverpod provider → screens pattern stays. Firestore mirror under `users/{uid}/{collection}`. flutter_local_notifications for reminders.

**Tech Stack:** Flutter 3.x, Drift 2.18, Riverpod 2.5, go_router 14, Firebase Auth/Firestore, Cloudinary HTTP upload, flutter_local_notifications, intl/ARB.

**Build target:** Android APK release, installs and launches on `emulator-5554` (API 37).

### Task 1.4: Auto-Farm-ID service

- [ ] Create `farm_id_service.dart`:

```dart
class FarmIdService {
  FarmIdService(this._db);
  final AppDatabase _db;

  /// Atomically increments counter and returns the next farm_id.
  Future<String> generate(String userId, String prefix) async {
    final year = DateTime.now().year;
    return _db.transaction(() async {
      final existing = await (_db.select(_db.farmIdCountersTable)
            ..where((t) =>
                t.userId.equals(userId) &
                t.prefix.equals(prefix) &
                t.year.equals(year)))
          .getSingleOrNull();
      final next = (existing?.lastNumber ?? 0) + 1;
      await _db.into(_db.farmIdCountersTable).insertOnConflictUpdate(
        FarmIdCountersTableCompanion(
          userId: Value(userId),
          prefix: Value(prefix),
          year: Value(year),
          lastNumber: Value(next),
        ),
      );
      return '$prefix-$year-${next.toString().padLeft(4, '0')}';
    });
  }

  /// Peek at the next id without incrementing (for form preview).
  Future<String> preview(String userId, String prefix) async {
    final year = DateTime.now().year;
    final existing = await (_db.select(_db.farmIdCountersTable)
          ..where((t) =>
              t.userId.equals(userId) &
              t.prefix.equals(prefix) &
              t.year.equals(year)))
        .getSingleOrNull();
    final next = (existing?.lastNumber ?? 0) + 1;
    return '$prefix-$year-${next.toString().padLeft(4, '0')}';
  }
}
```
